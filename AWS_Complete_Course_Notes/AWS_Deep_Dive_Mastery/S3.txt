S3:-Simple Storage Service
===========================
It is used to store static files like images, videos, css, js, documents,backups,logs,webapps,mobile apps,websites etc online
Access files using public URL
Files are stored in the form of Buckets like folders

Bucket name should be unique worldwide and no uppercase letters or special characters are allowed in the bucket name
It is highly Scalable, Durable, and Highly available
S3 has 99.999999999% durability and 99.99% availability
S3 Standard
1. S3 Standard
2. S3 Intelligent-Tiering
3. S3 Standard-IA
4. S3 One Zone-IA
5. S3 Glacier Instant Retrieval
6. S3 Glacier Flexible Retrieval
7. S3 Glacier Deep Archive

Each file is called as an object in S3

No need to pay for storage space or storage limit (they have virtual storage that can be increased)
easy to integrate with other AWS services and nodejs,react,Firebase, Django, Laravel and many more
low cast , pay as u go pricing

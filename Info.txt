EC2:- Elastic Cloud Computing
==============================================
It's like Virtual computer(Server) thats run in cloud
We can start, stop, restart , deploy whenever we want
its used to:- 1)Host webapps, websites
              2)Run backend Servers (Nodejs, Django)
              3)Testing or development remotly
              4)Web servers, App servers, Dev/Test environment
              5)AIML
              6)Scheduled tasks
              7)GPU, Train the Models


EC2 has its own IP Address connected with internet, There is public IP, and Elastic IP
EC2 Uses Elastic Block store(EBS) for storage
EC2 is like our Personal computer

Connecting EC2 Instance with remote access using SSH Protocol
=================================================
SSH:- Secure Shell Protocol
A Protocol used for secure communication over an unsecured network 
Used to manage remote systems 

powershell_in_the_folder_Where_key_Saved 
         --> ssh -i "copy_the_path_of_key_pair where_u_saved\key_name.pem" ec2-user@IPV4_address(of Instance running)
        eg:- ssh -i "D:\BRO\Devops\AWS\MyWebServerKey.pem" ec2-user@13.49.69.200 -->
It will give Permission denied --> icacls "MyWebServerKey.pem" /inheritance:r(It means, we have removed inheritance , removed unwanted access ) ->icacls "MyWebServerKey.pem" /remove:g "Administrators" "SYSTEM" (remove groups like administrator grops, system groups) "username" (to check ur username, go to cmd type whoami it will give a path, the first name is the username)
--> now grant access only to the current user , icacls "MyWebServerKey.pem" /grant:r sujan:F ---->icacls "MyWebServerKey.pem"(To check who are using this file) --> ssh -i "D:\BRO\Devops\AWS\MyWebServerKey.pem" ec2-user@13.49.69.200(Try this here, now it will be permitted, now we can do anything using aws instance in cli, Here we took remote access of EC2 using SSH, now no need of aws, we can do it using cli)
